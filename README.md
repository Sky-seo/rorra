# Rorra — Product Studio

Swap의 FORM 3D 컴포지션 스튜디오를 기반으로 만든 Rorra 전용 사이트입니다.

## 실행

이 폴더의 **Rorra.html**을 Chrome에서 더블클릭해 여세요. 인터넷이나 서버 없이 동작합니다. index.html도 동일한 실행 파일입니다.

## 모델과 기능

- Rorra AQM, Rorra DD, Rorra Shower CAD 내장. AQM이 처음 표시됩니다.
- 라이브러리의 제품 이름으로 선택/추가, + 버튼으로 같은 제품 추가.
- 세 제품 모두 인스펙터의 Finish 패널에서 **Metal · Black** 두 가지 머티리얼 선택. 기본값은 Metal이며 오브젝트별로 따로 지정됩니다.
- 카메라 회전·줌·원근감, 오브젝트 이동·회전·크기 조절.
- Camera timeline 패널에서 키프레임 기반 카메라 무빙. 키프레임은 Zoom · X/Y Rotation · Perspective 슬라이더 값을 그대로 담으며, Y -180°와 180°에 키를 찍으면 360° 턴테이블이 됩니다. **키프레임은 ＋ Keyframe을 누른 순간에만 찍힙니다** — 그 사이에 카메라를 아무리 돌려도 자동으로 추가되지 않습니다. 시작 뷰에서 한 번, 다른 각도를 잡고 한 번 누르면 키는 두 개이고 그 사이는 보간으로 이어집니다. 새 키에는 기본 2초 길이가 붙고 시간 입력으로 바꿀 수 있습니다.
- Play로 재생, 트랙 드래그로 스크럽, 마커나 Key 버튼으로 해당 뷰로 점프, ↺로 현재 뷰로 교체, ✕로 삭제.
- **↗ Save video**로 카메라 무빙을 MP4 영상으로 저장. 처음부터 끝까지 실시간 재생하며 뷰포트 캔버스를 그대로 녹화하고(H.264, 30fps, 캔버스 해상도 그대로), 기즈모는 빠집니다. 녹화 중에는 버튼이 ■ Stop recording으로 바뀌어 중간에 끊고 거기까지 저장할 수 있습니다.
- **Key 버튼을 누르면 그 키의 Ease in / Ease out 슬라이더가 열립니다.** Ease in은 그 키로 들어오는 구간, Ease out은 나가는 구간을 제어하며 0%는 등속, 100%는 키 앞뒤로 가장 오래 머뭅니다. 각 슬라이더 옆 곡선이 해당 구간의 실제 타이밍을 보여줍니다(연한 대각선이 등속 기준선). 첫 키의 Ease in과 마지막 키의 Ease out은 이어질 구간이 없어 비활성입니다.
- STEP/STP, GLB, OBJ, STL 파일 가져오기 및 PNG 이미지 저장.
- W 이동, E 회전, F 화면 맞춤, ⌘C/⌘V 복제, Delete 삭제.

원본 CAD는 보존됩니다. 제품은 화면에 맞게 각각 정규화되므로 제품 사이의 실제 크기 비율을 나타내지 않습니다. 피니시는 제품별로 파트 역할을 나눠 적용합니다. AQM·DD는 CAD 가스켓과 고무 받침을 무광 블랙으로 분리하고, Metal은 브러시드 스테인리스 본체, Black은 무광 차콜 코팅입니다. 본체와 스탠드 사이 씰은 레퍼런스 기반 시각 디테일로 추가했습니다. Shower는 전면 분사판과 중앙 메달리온을 CAD 좌표로 식별해, Metal은 미러 하우징·차콜 분사판·광택 화이트 메달리온, Black은 전체 블랙에 메달리온이 묻히는 디보스 로고로 구성했습니다. 반사 환경은 2K HDR 스튜디오 조명, 금속은 이방성 재질을 사용하며 CAD 곡면 테셀레이션과 그림자 해상도를 높였습니다.

AQM CAD에는 "rorra" 글자 5장이 두께 0의 스케치 면으로 리드 상단보다 약 90mm 위 작도 평면에 남아 있습니다. 아래의 스피곳 손잡이 상단은 돔형이라 이 평면 글자가 앉을 면이 없어, 공중에 뜬 채 모델 바운딩 박스를 517mm로 부풀려 정규화와 프레이밍까지 어긋나게 만들었습니다. 솔리드 전체보다 위에 있는 스케치 면은 렌더에서 제외합니다. 편집 내용과 업로드는 현재 세션에만 유지되며 새로고침하면 초기화됩니다.

## 개발

소스: composition-studio/. Node.js 22.12 이상이 필요합니다.

```sh
cd composition-studio
npm run dev
npm run build:standalone
npm test
```

현재 node_modules는 같은 컴퓨터의 Swap 프로젝트 의존성을 연결해 사용합니다. 다른 컴퓨터에서는 이 링크 대신 npm ci로 설치하세요. HTML 실행 파일은 이 링크에 의존하지 않습니다.

npm run build는 dist/ 배포 폴더를, npm run build:standalone은 상위 Rorra.html과 index.html을 생성합니다. npm test는 설치된 Google Chrome에서 네트워크를 끈 상태로 CAD 3종, 메탈 재질, 제품별 피니시 2종 전환, 부유 스케치 면 제거, 카메라 타임라인(명시적 클릭에서만 키 생성, 스크럽, 이징 0%의 등속성과 100%의 지연, 재생 종료 위치, Y -180°→180°의 360° 회전, MP4 영상 저장), 크기, 카메라, PNG 저장, 모바일 너비 및 런타임 오류를 검증합니다.

Rorra.html은 약 12.4MB입니다. occt WASM과 STEP 원본을 모두 gzip한 뒤 base64로 임베드하고 런타임에 DecompressionStream으로 복원합니다. WASM을 압축하지 않으면 base64만으로 9.7MB를 차지해 전체가 19MB를 넘습니다.

영상 저장은 canvas.captureStream(30) + MediaRecorder라 추가 라이브러리 없이 오프라인에서 동작합니다. MP4/H.264를 우선 쓰고, MediaRecorder가 MP4를 못 쓰는 구형 브라우저에서는 WebM으로 자동 대체하며 둘 다 안 되면 그 사실을 알리고 중단합니다. 실시간 녹화이므로 영상 길이는 타임라인 길이와 같고, 재생이 끊기면 영상도 끊깁니다 — 무거운 모델에서 길게 뽑을 때는 먼저 Play로 프레임이 매끄러운지 확인하세요. MediaRecorder는 가변 프레임 타임스탬프로 기록하므로, 고정 30fps를 요구하는 편집 툴에서는 `ffmpeg -i in.mp4 -r 30 out.mp4`로 맞추세요.

구간 이징은 CSS와 같은 cubic-bezier(x1, 0, x2, 1) 모델입니다. 떠나는 키의 Ease out이 x1, 도착하는 키의 Ease in이 1-x2가 되어, 한 구간의 타이밍을 양 끝 키가 함께 결정합니다. 0%/0%는 정확히 등속이고 기본값은 양쪽 50%입니다. 재생 시 x(t)=진행률을 Newton 반복으로 풀어 t를 구한 뒤 y(t)를 읽습니다.

카메라 키프레임은 월드 좌표가 아니라 궤도 자체(타깃·거리·각도·FOV)를 저장합니다. 월드 위치를 보간하면 두 뷰 사이에서 카메라가 제품을 뚫고 지나갑니다. 거리는 기하 보간합니다 — 선형으로 하면 먼 뷰에서 가까운 뷰로 갈 때 초반이 거의 멈춰 있다가 끝에서 급격히 밀려듭니다.

각도는 최단 경로가 아니라 **슬라이더에 찍힌 값 그대로** 쓸립니다. 카메라 무빙은 Y Rotation 슬라이더를 한 값에서 다른 값까지 따라가며, 중간 값을 모두 지납니다. 따라서 Y -180°에서 키를 찍고 180°에서 키를 찍으면 360° 한 바퀴를 돕니다(최단 경로였다면 차이가 0으로 접혀 전혀 움직이지 않습니다). 반대로 170°에서 -170°로 찍으면 20°가 아니라 -340°를 돕니다 — 짧게 넘기려면 그 사이에 키를 하나 더 두세요.

Three.js 및 occt-import-js를 사용하며 STEP 라이선스는 composition-studio/public/vendor/LICENSE.occt-import-js.md와 HTML 내부에 포함되어 있습니다.
